# pizzeria-analytics
# 🍕 Аналитический дашборд для пиццерии: SQLite, Power BI, бизнес-выводы

## 📌 О проекте

**Цель:** Создать аналитический дашборд для владельца пиццерии, который позволит:
- Отслеживать ключевые метрики бизнеса
- Выявлять точки роста
- Принимать управленческие решения на основе данных

**Данные взяты за период:** 27 мая – 2 июня 2025

**Результат:** Выявлены зоны роста, позволяющие увеличить выручку на 15–20% без привлечения новых клиентов.

---

## 🔧 Инструменты

| Инструмент | Назначение |
|------------|------------|
| SQLite | Хранение и обработка данных |
| SQL | Написание запросов, создание таблиц |
| Power BI Desktop | Визуализация данных, DAX-меры |
| DAX | Вычисляемые метрики |
| GitHub | Хранение кейса |

---

## 📊 Ключевые метрики

| Метрика | Значение |
|---------|----------|
| Общая выручка | 90 040 руб. |
| Средний чек | 500 руб. |
| Всего заказов | 180 |
| Продано позиций | 281 |
| Доля пиццы в выручке | 69% |
| Доля доставки | 66% |

---

## 🧠 Ключевые инсайты

1. **Пицца — основной драйвер бизнеса (69% выручки)**
2. **Десерты и салаты — зона роста (6% и 12% в чеке)**
3. **Доставка доминирует (66%), но увеличивает затраты**
4. **Два пика спроса:** обед (17 заказов/час) и ночь (19 заказов в 23:00)
5. **Утро (до 11:00) — низкий спрос,** инвестиции нецелесообразны
